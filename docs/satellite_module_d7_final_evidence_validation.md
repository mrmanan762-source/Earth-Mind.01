## 1. Overview and Core Purpose

Stage D7 implements the final validation and governance layer for satellite intelligence evidence generated by Stage D6. Before any satellite observation or agricultural indicator can be delivered to the B2 Context Manager and reasoned upon by Sarvam-105B, it must pass strict multi-dimensional validation.

The Satellite Module provides satellite data capabilities, processing, and validated intelligence. Sarvam-105B remains EarthMind's primary AI reasoning model. The validation gate ensures that corrupted, contradictory, out-of-bounds, or uncalibrated satellite data never reaches the reasoning model.

---

## 2. Validation Architecture

Validation is executed by `SatelliteEvidenceValidator` (`modules/satellite/evidence_validator.py`) across 8 core dimensions:

1. **Contract Schema & Identity:**
   - Contract name must equal `"EarthMindSatelliteEvidence"`.
   - Schema version must equal `"1.0"`.
   - `evidence_id` must be a non-empty, unique identifier.

2. **Source Provenance & Mission Identity:**
   - Provider identifier (`provider_id`), constellation, spacecraft platform, and sensor/instrument must be non-empty strings.
   - Origin dataset ID (`dataset_id`) must be verified.
   - Cryptographic SHA-256 evidence hash verification (`evidence_hash` in provenance).

3. **Spatiotemporal Plausibility:**
   - Centroid latitude bounded in $[-90.0, 90.0]$ and longitude in $[-180.0, 180.0]$.
   - Bounding box consistency check (`min_lat <= max_lat` and `min_lon <= max_lon`), rejecting inverted coordinates.
   - ISO 8601 UTC acquisition timestamp present and validated.

4. **Quality & Atmospheric Integrity:**
   - Cloud cover percentage bounded in $[0.0, 100.0]$.
   - Cloud obscuration policy: cloud-obscured scenes generate operational warnings or fail closed under strict mode.

5. **Physical Radiometric Sanity:**
   - Band surface reflectance mean values checked against physical bounds $[-0.05, 1.50]$.

6. **Indicator Statistics & Scientific Bounds:**
   - Normalized difference indices (NDVI, NDRE, NDWI variants, EVI) bounded within $[-1.0, 1.0]$.
   - Unit verification (`dimensionless` or `unitless_ratio`).

7. **Uncertainty & Confidence Consistency:**
   - Spatial, temporal, spectral, and overall confidence scores bounded in $[0.0, 1.0]$.
   - Contradiction rejection: forbids high overall confidence (>0.40) on `INVALID` quality data, or high spectral confidence (>0.50) on >70% cloud cover.

8. **Attribution & Status Consistency:**
   - Mandatory provider license attribution check (e.g. Copernicus, USGS, ISRO).
   - Rejects `REJECTED` or `FAILED` evidence from reaching context synthesis.

---

## 3. Explicit Machine-Readable Outcomes

`SatelliteEvidenceValidator` categorizes results into clear, machine-readable outcomes via `ValidationOutcome`:
- `VALID`: Evidence satisfies all structural, physical, and uncertainty rules.
- `VALID_WITH_WARNINGS`: Evidence is valid for reasoning but carries non-fatal operational warnings (e.g., partial cloud cover).
- `INSUFFICIENT_EVIDENCE`: Missing necessary indicators or observations for conclusive assessment.
- `INVALID`: Evidence violates physical bounds, coordinate geometry, or uncertainty rules.
- `REJECTED`: Explicitly flagged as rejected or failed at upstream processing stages.
